# 长任务与账号独立串行

用户确认取消 100 次上限，仍填写正整数；不增加无限循环模式。

- 输入使用 Python 整数，后台不截断为 100；停止/禁言/连续未确认等既有提前结束条件继续生效。
- 串行改为每账号一条独立顺序队列。一个账号完成并清理本房间后可前往下一房间，不等待其他账号。同账号不重叠房间；并行模式仍保留最多 3 个房间。
- 状态列显示运行/等待/结束。运行中的账号以蓝色显示实时进度；部分展示以橙色显示，停发原因保留在文字和详情。所有房间全部明确失败才使用红叉。
- 旁观监听成功建立后断开，最多重连 3 次，复用访客会话、保留订阅和已收到弹幕；不重发评论、不重连账号心跳。断线覆盖到的消息无法证明未展示，按监听不可用处理且重置连续未确认计数；完整观察窗口结束的旧结果保持原判定。
- 关闭/取消打断重连等待并关闭当前连接，等待线程退出。串行下一房间始于该账号清理返回后。

验证包括超过 100 次的离线发送链路、超过 Qt 整数范围的输入、超大计划数取消、105 个房间顺序遍历、快慢账号独立推进、多房间颜色汇总、断线恢复后继续收取弹幕、重连耗尽、退出房间取消重连、账号心跳不受旁观重连策略影响。发布使用干净源文件暂存、完整回归、EXE 内代码验证和隔离启动测试；不使用真实账号发送测试评论。
