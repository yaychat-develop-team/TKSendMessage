# 匿名监听 SOCKS5 代理

在 **运行设置 → 监听连接 → 匿名监听 SOCKS5 代理** 填写：

- `主机:端口`
- `主机:端口:用户名:密码`
- `socks5://用户名:密码@主机:端口` 或 `socks5h://用户名:密码@主机:端口`

URL 形式的凭据包含 `@`、`:`、`/`、`#` 等保留字符时需要百分号编码；简写的密码可以包含冒号。IPv6 使用 URL 方括号形式。用户名和密码分别不超过 127 个 UTF-8 字节，避免当前 SOCKS 库的长度编码限制。

留空保持原有网络选择。填入后只影响匿名访客初始化、匿名 WSS 监听和重连，目标域名由代理解析。账号的直播页查询、fetch、发消息与账号心跳保持原来的网络方式；不会将账号 Cookie 发给新的匿名代理链路。

代理连接或认证失败不会自动绕过代理直连。停止任务或离开直播间时，所属连接会被关闭；重连继续使用本次任务的相同代理。

默认隐藏输入，可勾选“显示代理内容”。运行中设置只读。格式错误时不保存，错误信息不回显凭据。代理信息随运行设置保存在本机，不是加密保管，请勿把运行设置文件发给别人；干净分发包不应携带运行数据。

该功能已包含在 2026.10.26.3 发布包中。在线验证使用匿名会话，无账号 Cookie、无评论发送。
